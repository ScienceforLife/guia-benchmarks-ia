# Guía de benchmarks de IA

Qué mide cada benchmark de inteligencia artificial, para qué decisión sirve y cuándo no debe usarse. Incluye evaluaciones generales, de código, de agentes y de salud.

Versión preliminar. Consulta de fuentes: 9 de noviembre de 2026.

Es una página estática (`index.html`), sin dependencias ni proceso de compilación. Se publica con GitHub Pages desde la rama `main`, carpeta raíz.

La guía no incluye puntajes actuales: cambian con frecuencia y deben consultarse en la tabla de resultados de cada instrumento. Cada fila enlaza a la fuente primaria.
